## Lessons Learned

- [2026-09-04 22:24] [Lessons Learned] npm braucht Workspace-lokalen Cache — TERRA-Projekt (/home/peter/Projekte/WebSim): npm install scheitert mit EROFS, wenn npm den Standard-Cache /home/peter/.npm nutzt (Sandbox). Lösung: `npm install --cache ./.npm-cache` (Workspace-lokaler Cache, in .gitignore). Geschwindigkeit-Zerlegung: kleine Tasks, ein Commit pro Task, Format "M<n>: <Task>".
- [2026-09-05 16:30] [Lessons Learned] TERRA: schwarzer Canvas = fehlendes renderer.setWorld beim Bootstrap — TERRA UI-Bugfix (3782566): Schwarzer Canvas lag daran, dass main.ts renderer.setWorld(initialWorld) beim Erststart nie aufrief (nur in applyLoadedWorld) — Renderer.draw() bricht ohne Welt ab, nur die Minimap zeigte etwas. Kamera (x/y = Sichtfeld-ZENTRUM) startet jetzt auf Kartenmitte statt (0,0). HUD: linke Spalte (Status/Stats/Budget/Städte) + rechte Spalte (Speed/Steuern/Minimap) als Flex-Stacks mit leftSlot/rightSlot-Gettern; vorher kollidierte das Tax-Panel (Inline top:48px) mit der Minimap (top:48 right:8) und Budget/City/Stats überlappten sich per fixer Tops. Minimap-Sichtfeldrechteck nutzt camera.viewSize statt der eigenen Canvas-Grösse. Lehre: bei „Canvas schwarz, Minimap zeigt Karte" zuerst prüfen, ob ALLE Renderer die Welt bekommen haben.
